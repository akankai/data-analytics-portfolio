# Data

The project uses a synthetic CSV file: [`sales_data.csv`](sales_data.csv).

- 1,001 rows (1,000 valid orders + 1 blank record)
- 12 fields (Date, Order_ID, Product, Category, Region, Sales_Channel, Units_Sold, Unit_Price_MAD, Unit_Cost_MAD, Promotion, Revenue_MAD, Cost_MAD, Profit_MAD)
- UTF-8 encoding with BOM on the Date column

The data is synthetic and created for portfolio/learning purposes.
