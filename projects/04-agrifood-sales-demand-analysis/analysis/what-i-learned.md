# What I Learned — AgriFood Sales & Demand Analysis

1. **A statistically significant result is not automatically a useful result — but here it is both.** The promotion margin difference is highly significant (p < 0.001) *and* has a large effect size (Cohen's d ≈ 0.85), which means it is both detectable and practically substantial. This is the best-case scenario for statistical testing, and it reinforced my understanding that the value of a statistical test depends on both the p-value and the effect size. The earlier P01 viscosity correlation (p = 0.012 but r = −0.117, R² = 1.4%) is the counterexample — significant but useless.

2. **The category-level control changed the interpretation.** Before the control, the overall margin gap (33.02% vs. 27.78%) could have been explained by promotions being concentrated in low-margin categories like Oils. The category-by-category analysis (sql/09_promotion_by_category.sql) showed the gap is consistent across all five categories, ruling out that explanation. This taught me that a confounder check can change the conclusion, and that it's worth doing even when the initial result looks clear.

3. **Mann-Whitney U and Welch t-test both matter for this kind of data.** The margin data is bounded (0%) and right-skewed, which violates the normality assumption of a t-test. But with large sample sizes, the t-test is still defensible for comparing means. The Mann-Whitney U test, which doesn't assume normality, gives a consistent result (both p < 0.001), which strengthens the conclusion. I learned to run both when the data is non-normal, and to report the one that matches the question (means vs. distributions).

4. **The business ambiguity is real and important.** The statistical analysis confirms the margin gap is real and large, but it cannot answer the question that actually matters for business decisions: does the margin loss get offset by higher volume? The dataset doesn't contain volume elasticity or customer acquisition data, so the answer is genuinely unknown. I learned that delivering a clear "the gap is real" finding alongside a clear "the net impact is unknown" acknowledgment is more useful than pretending the analysis can answer the business question.

5. **SQL reproducibility is a real advantage.** Having the analysis in standalone SQL scripts (01–09) means the findings can be verified independently of the Power BI dashboard. Anyone can run the SQL against the CSV and reproduce the numbers. This is a practical advantage for a portfolio — it shows the analysis is not just a dashboard with filters, but a documented, reproducible analytical process.
