# What I Learned — Production Performance & Efficiency Analysis

1. **OEE is more informative than any single KPI.** Yield, efficiency, waste rate, and utilization each tell part of the story, but OEE (Availability × Performance × Quality) integrates them into a single measure of how much planned good output is actually achieved. The decomposition showed that Performance (93.88%) is the largest loss driver, not Quality (97.50%) — a distinction that would be invisible if I only looked at defect rate or waste rate. I learned to always decompose a composite problem before prioritizing interventions.

2. **M03's problem is different from M04's.** M03 has the lowest OEE (83.8%) driven by downtime and utilization — an availability problem. M04 has a relatively high utilization (94.75%) but the highest waste rate (3.19%) — a process/material problem. The same "low OEE" label would hide very different root causes. I learned to always compare machines on multiple dimensions before concluding what the problem is.

3. **The production gap is a Performance problem, not a Quality problem.** The 35,927 kg below plan is driven more by not achieving planned output during operating time (Performance loss) than by defects (Quality loss of only 2.50%). This means the biggest improvement opportunity is in closing the actual-to-planned gap and reducing downtime, not in reducing defects. I learned to let the decomposition guide prioritization, not intuition.

4. **A simple operational cost model makes the analysis decision-relevant.** Valuing downtime at an illustrative 500 MAD/hour turns M03's 4,823.5 minutes of downtime into an estimated 40,196 MAD in downtime cost (illustrative). Combined with the waste cost and the production gap cost, the analysis moves from "M03 is the worst machine" to "M03 is the worst machine and here is an illustrative cost range for the losses." I learned that even with assumed parameters, a transparent cost model is more useful for prioritization than a list of KPIs.

5. **December vs. May comparison is a natural experiment.** December's stronger OEE (87.5%) vs. May's weaker OEE (85.8%) is a 1.7 pp difference that could reveal repeatable improvement actions — but only if I can identify what was different between those months (staffing, maintenance schedule, product mix, raw material). The dataset does not contain that context, so the comparison is a signal for investigation, not an explanation. I learned that comparing good vs. bad periods is useful only when you can also identify what differed between them.
