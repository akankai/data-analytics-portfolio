# Data Dictionary

| Field | Description | Unit / Type |
|---|---|---|
| Date | Production date/time | DateTime |
| Product | Manufactured chocolate product | Category |
| Machine | Production machine identifier | Category |
| Shift | Production shift | Category |
| Operator | Operator identifier | Category |
| Batch_ID | Unique production batch identifier | Text |
| Planned_Production_kg | Planned production quantity | kg |
| Actual_Production_kg | Actual production quantity | kg |
| Production_Gap_kg | Actual production minus planned production | kg |
| Input_Quantity_kg | Input/raw quantity used | kg |
| Good_Output_kg | Good output quantity | kg |
| Waste_kg | Production waste quantity | kg |
| Downtime_min | Recorded downtime | minutes |
| Available_Time_h | Available production time | hours |
| Operating_Time_h | Actual operating time | hours |
| Energy_Consumption_kWh | Energy consumed during production | kWh |
