# Power BI

The Power BI report contains the interactive **Inventory & Supply Chain Analysis** dashboard.

## Dashboard purpose

The report is designed to monitor:

- Inventory value
- Stockout exposure
- Low-stock exposure
- Supplier delivery reliability
- Inventory turnover

## Filters

- Category
- Supplier
- Warehouse

## Documentation

- `dashboard.md` — visual inventory and dashboard notes
- `dax-measures.md` — documented KPI measures

> The `.pbix` report used for this project is retained with the project source material. The repository documentation captures the model logic and dashboard structure.
