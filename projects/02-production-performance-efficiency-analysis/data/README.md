# Data

The project uses a synthetic Excel workbook containing **500 production records**.

The data covers:

- 5 products
- 4 machines
- 3 shifts
- 8 operators
- 2025 production dates

The workbook is included for reproducibility and learning. It does **not** contain real or confidential company data.

The Power BI dashboard calculates KPIs from the raw operational fields using DAX.
